# NVS Crop Passport Site

Website GitHub Pages cho hộ chiếu sản phẩm công khai của NVS. **Không chứa dữ liệu tài chính hoặc thông tin cá nhân** từ repository nội bộ `nvs-crop-passport`.

## Website
https://phanminhtuandalat.github.io/nvs-crop-passport-site/

## Mã QR thử nghiệm
https://phanminhtuandalat.github.io/nvs-crop-passport-site/?lot=DEMO-BHD-2026-001

**QUAN TRỌNG:** Đây chỉ là mã DEMO minh họa, chưa có lô bí thật được thu hoạch hoặc kiểm nghiệm. Tuyệt đối không in mã này lên sản phẩm đang bán.

## Trạng thái và nguyên tắc
* Vụ bí Chi's Farm dự kiến xuống giống ngày 19/10/2026. Chưa xác nhận ngày xuống giống thực tế.
* Không có lô thu hoạch thật được phê duyệt hay kết quả xét nghiệm nào công bố.
* Không công khai bảng chi phí, hợp đồng, thông tin khách hàng, dữ liệu riêng tư hoặc giá mua nội bộ.
* Chỉ phát hành mã truy xuất thực khi có mã lô, dữ liệu chăm sóc, số liệu thu hoạch, tiêu chí phân loại và người duyệt rõ ràng.
* Mã QR là đường dẫn, tự nó không chứng minh nguồn gốc hay chất lượng.

## Triển khai
GitHub Pages, source main branch và root folder. Website thuần HTML + CSS + JavaScript, không có backend. Về sau chỉ công bố dữ liệu đã được phê duyệt từ hệ thống nội bộ (Supabase/OMA). Không dùng GitHub public repo làm cơ sở dữ liệu đơn hàng.
